# Tier 0 Bundle Signing Ceremony (owner-only)

**Scope.** This ceremony produces the Ed25519 signature that lets a Tier 0
offline bundle pass `loadSignedTierZeroBundle()`. It is performed by the owner,
on an offline machine, with a key that has never touched this repository or a
network-connected host. Finding F1-09 / PG-13 is closed by the custody rules
below, not by a key stored in the tree.

> **NO private key is in this repository.** Not in source, not in `settings/`,
> not in `artifacts/`, not in git history. `tools/secrets-scan.mjs` flags a
> private-key PEM header anywhere in the published tree or any git blob, and
> the scan must stay clean. The keypair returned by `generateTestKeyPair()` and
> every key generated by a unit test is **NON-PRODUCTION test material**; it
> must never sign a real Tier 0 bundle. Production trust comes only from the
> owner-generated key held in KMS/HSM or an offline vault.

## 0. invariant

The bytes signed and the bytes verified must be identical. Both the signer
(`tools/sign-tier-zero.mjs`, `canonicalBytes`) and the verifier
(`src/ed25519-signature.ts`, `canonicalBundleBytes`) emit UTF-8 JSON with keys
in the fixed order `version`, `watermark`, `lessons` (each lesson `id` then
`body`). The `signature` field is never included. Do not change one side
without the other.

## 1. Generate the keypair — offline machine, outside the repo

Work in an empty directory that is **not** inside the EduGenesis OS build tree.
This writes an SPKI public key and a PKCS#8 private key as PEM text; the headers
are produced by the runtime and are never pasted into a repository file.

```bash
mkdir -p /secure/offline/edugenesis-bundle && cd /secure/offline/edugenesis-bundle
node -e "const {generateKeyPairSync}=require('node:crypto');const fs=require('node:fs');const k=generateKeyPairSync('ed25519',{publicKeyEncoding:{type:'spki',format:'pem'},privateKeyEncoding:{type:'pkcs8',format:'pem'}});fs.writeFileSync('bundle-public.pem',k.publicKey);fs.writeFileSync('bundle-private.pem',k.privateKey);"
chmod 600 bundle-private.pem
```

## 2. Custody

- Move `bundle-private.pem` into KMS/HSM or an offline vault. Restrict access
  to the owner only. It must never be copied into the repo, a CI runner, a
  settings file, an environment file, or a chat/log transcript.
- Keep `bundle-public.pem` for configuration; the public key is safe to embed.
- Record the key's fingerprint and creation date in the owner's offline log.
  Never record the key itself.

## 3. Embed the public key in verifier config

Provide the SPKI PEM text to the deployment's verifier configuration through
the deployment's normal secret-free config path, then build the package. The
verifier is constructed with:

```ts
const verifier = createEd25519Verifier(publicKeyFromConfig);
```

Do not construct a verifier from a randomly generated key in production —
`generateTestKeyPair()` is test/ceremony-only.

## 4. Sign — offline machine, key path from env only

The signer refuses to run if `EDUGENESIS_BUNDLE_SIGNING_KEY` is unset or if the
resolved key path is inside the repository root. It never prints key material.

```bash
EDUGENESIS_BUNDLE_SIGNING_KEY=/secure/offline/edugenesis-bundle/bundle-private.pem \
  node tools/sign-tier-zero.mjs artifacts/tier-zero-bundle.json artifacts/tier-zero-bundle.sig
```

Publish the bundle JSON and its `.sig` file together; a change to any signed
field invalidates the signature and requires a new ceremony run.

## 5. Verify — before promoting the bundle

After the build, verify against the configured public key. The path below
assumes the source module sits beside `signed-bundle.ts` in
`packages/onekey/src/registry/` and compiles to `dist/registry/`; adjust if the
layout differs.

```bash
node -e "const {createEd25519Verifier,loadSignedTierZeroBundle}=require('./packages/onekey/dist/registry/ed25519-signature.js');const fs=require('node:fs');const pub=fs.readFileSync('/secure/offline/edugenesis-bundle/bundle-public.pem','utf8');const b=JSON.parse(fs.readFileSync('artifacts/tier-zero-bundle.json','utf8'));b.signature=fs.readFileSync('artifacts/tier-zero-bundle.sig','utf8').trim();console.log('verified:',loadSignedTierZeroBundle(b,createEd25519Verifier(pub)).version);"
```

Run the signing test suite too:

```bash
node --test packages/onekey/dist/registry/ed25519-signature.test.js
```

## 6. Owner checklist

- [ ] Keypair generated on an offline machine, outside the repo.
- [ ] Private key stored only in KMS/HSM or an offline vault; never in the tree.
- [ ] Public key embedded in verifier config and reviewed by the owner.
- [ ] `EDUGENESIS_BUNDLE_SIGNING_KEY` set to an external path; never committed.
- [ ] Bundle JSON + `.sig` published together; signature verifies with the public key.
- [ ] `tools/secrets-scan.mjs` reports zero findings (no key material in tree or history).
- [ ] No test-generated key was used to sign a production bundle (F1-09 / PG-13).
